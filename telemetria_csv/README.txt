========================================================================
 CARPETA DE IMPORTACION DE ARCHIVOS GPS / CSV
========================================================================

Coloca aqui tus archivos CSV con el historial de GPS de la flota.

El script de importacion admite:
- Archivos .csv de cualquier tamano (admite millones de filas por streaming).
- Delimitadores automaticos: coma (,) o punto y coma (;).
- Mapeo automatico de columnas (Patente, Fecha/Hora, Latitud, Longitud, Velocidad, Estado/Evento, Rumbo, Odometro).

Para iniciar la importacion tras copiar los archivos, ejecuta:
  node scripts/importar-gps-csv.js
O solicitamelo directamente en el chat para ejecutarlo.
========================================================================
